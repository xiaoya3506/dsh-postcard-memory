# 📮 明信片 · DSH 记忆插件

> 一个"干净"的本地跨会话记忆插件。
> 名字的由来：记忆就是**留给下一个自己的话**，像寄一张明信片。

---

## 它解决什么问题

对话越来越长，早晚会满。满了开新对话，新对话里就想不起之前的事。

这个插件提供一个**本地的、可读的、按工作区隔离的**记忆库，
让新会话能主动查到之前记下的东西。

---

## 它**不**做什么（重点）

主人列的 5 条标准，逐条对照：

| # | 标准 | 本插件怎么做 |
|---|---|---|
| ① | **不自动往上下文里塞东西** | **没有 pre-step / pre-message 钩子。** 记忆只通过**工具返回值**出现——模型主动调用 `memory_read` 才看得到 |
| ② | **不冒充主人说话** | **从不产生 `role:user` 消息。** 源码里搜不到 `role` 字段 |
| ③ | **不指使改配置** | 只 `import node:fs` / `node:path` / `dsh-tools`。**不读 settings.yaml，不写 package.json** |
| ④ | **支持单个工作区隔离** | 记忆路径 = `<当前工作区>/.whale-memory/`。**不同工作区天然互不可见** |
| ⑤ | **记忆存本地** | **纯 markdown 文件。** 无网络请求、无数据库、无外部服务、无凭证 |

**另外，代码里没有：** `fetch` / `http` / `child_process` / `eval`。

## 关于"首次提示"

主人要求：第一次运行时要提示一句"需要记忆时怎么查"，而且**明确标注这不是主人说的话**。

**本插件的做法（三重保险）：**

1. **走 `systemPrompt.section`** —— 角色是 `system`，**机制上就不可能是 `user`**
2. **正文第一行就是免责声明**：
   ```
   ┌─────────────────────────────────────────────────────┐
   │  [记忆插件「明信片」提示 · 非主人发言]              │
   └─────────────────────────────────────────────────────┘
   ```
3. **只出现一次** —— 注入后立刻写标记文件 `.first-run-done`，之后再也不注入

**对比一下那个被卸掉的插件：**

| | meow-memory | 明信片 |
|---|---|---|
| 注入通道 | `first-message injection`（**伪装成用户消息**） | `systemPrompt.section`（系统通道） |
| 内容 | 指使改 `promptLang` 配置 | 只说明怎么查记忆 |
| 频率 | 每次/首次 | 仅一次 |
| 是否标注来源 | ❌ 不标注 | ✅ 第一行就标注 |

## 三个工具

### `memory_read` —— 读记忆

```
memory_read                        → 最近 20 条
memory_read { limit: 50 }          → 最近 50 条
memory_read { entry: "事实" }       → 某个条目全文
```

### `memory_write` —— 写记忆

```
memory_write { content: "主人喜欢简洁的回答", title: "偏好" }
memory_write { entry: "教训", content: "不要目测坐标点网页", title: "CDP" }
```

### `memory_list` —— 列目录

```
memory_list                        → 有哪些条目、多大、什么时候改的
```

## 存储结构

```
<工作区根目录>/
└── .whale-memory/
    ├── .first-run-done          ← 首次提示已发出的标记
    ├── 记忆.md                   ← 默认条目
    ├── 事实.md                   ← 长期事实
    └── 教训.md                   ← 踩过的坑
```

**每个文件长这样（纯 markdown，人可读）：**

```markdown
# 记忆

## [2026-10-07 15:04:05] 偏好

主人喜欢简洁的回答，不喜欢废话。

## [2026-10-07 16:20:11] 工具

Termux 桥在 127.0.0.1:8081，token 在 ~/whale/auth.env。
```

**主人随时可以：**
- 用任何文本编辑器打开看
- 直接改内容
- 删掉不想留的
- 用 git 版本管理

## 安全边界

| 项 | 值 |
|---|---|
| **单条内容上限** | 8000 字符 |
| **单文件上限** | 256 KB（超了会拒绝写入，防止无限膨胀） |
| **单次读取上限** | 100 条 |
| **条目名限制** | 只能中文/字母/数字/`_`/`-`/`.`，禁止路径分隔符 |
| **路径限制** | 记忆目录**必须**位于工作区之下，拒绝含 `..` 的路径 |

## 安装

```bash
# 方式 1：从本地目录装
dsh plugin --profile web add /path/to/明信片插件

# 方式 2：如果是 git 仓库
dsh plugin --profile web add github:<用户名>/dsh-postcard-memory
```
